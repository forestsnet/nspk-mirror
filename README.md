# Зеркало оплаты СБП

С ночи 24→25 ноября 2026 `qr.nspk.ru` и API, к которым ходит его страница (`upc`, `widget`, `crt.cbrpay.ru`), отдают сертификаты Russian Trusted Sub CA → Russian Trusted Root CA (НУЦ Минцифры). Браузеры, кроме Яндекс Браузера, им не доверяют, и ссылка на оплату по QR в Safari или Chrome упирается в ошибку сертификата.

Зеркало отдаёт страницу оплаты со своего домена под обычным сертификатом. Платёжный шлюз выдаёт ссылку `https://qr.nspk.ru/<QRC_ID>?…`, проект подменяет в ней хост на зеркало, а зеркало показывает свою страницу выбора банка. Нажатие на банк открывает его приложение с уже заполненным платежом.

## Подмена ссылок

В ссылке от шлюза меняется только начало `https://qr.nspk.ru/` на адрес зеркала. Путь и query сохраняются как есть, в них может быть `crc` статического QR.

```
https://qr.nspk.ru/BD10103IQ18O3ISP8RGAM6FN3AP1N0GH?type=02&sum=15630&cur=RUB
https://sbp.example.com/BD10103IQ18O3ISP8RGAM6FN3AP1N0GH?type=02&sum=15630&cur=RUB
```

В QR-картинку, которую проект рисует сам, лучше класть исходную ссылку НСПК. Встроенные сканеры приложений банков узнают платёж именно по `qr.nspk.ru`.

## Что отдаёт зеркало

| Путь | Что это |
|---|---|
| `/<QRC_ID>` | Своя страница: сетка банков с диплинками, поиск, недавний банк первым, QR-код, помощь «Не работает оплата?» |
| `/logo/{40,80,120}/bankXXXXXXXXXXXX.png` | Логотипы банков точно под плитку для экранов ×1, ×2, ×3 (GD, кэш на диске) |
| `/nspk/<QRC_ID>` | Страница НСПК целиком, запасной вариант, ссылка на неё есть в «Не работает оплата?» |
| `/proxyapp/…`, `/static/…`, `/js/…`, `/woff2/…` | Статика НСПК через прокси, логотипы и картинки с дисковым кэшем |
| `/_cbr/{upc,widget,crt}/…` | API cbrpay.ru для страницы НСПК (payment-link, список банков, проверка сертификата) |
| `/_mirror/health` | Проверка живости, апстрим не трогает |
| `/`, `/serviceWorker.js` | 404. Service worker НСПК на корне перехватывал бы `/<QRC_ID>`, поэтому он живёт только под `/nspk/` |

Ссылки в банки строятся так же, как на странице НСПК. Если у банка включён веб-клиент, ссылка ведёт на него (Т-Банк, ВТБ, Альфа и ещё около 70 банков), иначе на схему приложения `bankXXXXXXXXXXXX://qr.nspk.ru/<QRC_ID><query>`. Хост в диплинке всегда `qr.nspk.ru`, другой приложения банков не примут.

На телефоне первой показывается сетка банков, QR-код открывается кнопкой и сохраняется картинкой для загрузки в приложение банка. На компьютере первым идёт QR-код: режим «Приложением банка» кодирует исходную ссылку НСПК, «Камерой телефона» кодирует адрес этой же страницы на зеркале. Сумма в шапке показывается, когда в ссылке есть `sum` в копейках.

### Откуда берутся банки

1. `https://widget.cbrpay.ru/v2/sbp/members/qr` с заголовком `X-CLIENT-ID: 000000000000`. Это тот же API, что у страницы НСПК: готовые шаблоны ссылок и актуальные логотипы.
2. Если он не ответил, `https://qr.nspk.ru/proxyapp/c2bmembers.json`. У ВТБ там устаревший id `110000000005` без логотипа, в остальном ссылки совпадают с v2.
3. Последний рубеж — снимок `data/c2bmembers.json` в репозитории.

Список кэшируется на 10 минут, логотипы и статика на сутки и неделю. Протухшая копия отдаётся, если апстрим не ответил. Кэш лежит в томе `cache` и переживает пересборку.

### Проверка сертификата апстрима

Цепочку Russian Trusted Root CA зеркало сознательно не проверяет (`CURLOPT_SSL_VERIFYPEER=false`), корень Минцифры в образ не кладётся. Цена решения: тот, кто встанет между зеркалом и НСПК, сможет подменить список банков и ссылки в них. Поэтому всё, что попадает в `href`, сверяется с шаблонами: схема `bankXXXXXXXXXXXX://qr.nspk.ru/{QRC_ID}…` или `https://…` с `{QRC_ID}`. Остальное отбрасывается.

## Локальный запуск

```bash
docker compose up -d --build
```

Страница: `https://127.0.0.1:8443/<QRC_ID>`. Сертификат на 8443 самоподписанный, браузер попросит подтвердить исключение. По HTTPS страница НСПК проходит свои проверки адресов (`https://` в конфиге и логотипах), поэтому локально смотреть её стоит именно так.

## Прод

Контейнер слушает `127.0.0.1:8080`, TLS снимает nginx на хосте с сертификатом Let's Encrypt. Зеркалу нужен отдельный домен или поддомен целиком: статика НСПК раздаётся с корня.

```bash
MIRROR_ORIGIN=https://sbp.example.com docker compose up -d --build
```

```nginx
server {
    listen 443 ssl;
    http2 on;
    server_name sbp.example.com;

    ssl_certificate     /etc/letsencrypt/live/sbp.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/sbp.example.com/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto https;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 30s;
    }
}
```

`MIRROR_ORIGIN` задаёт адрес, на который переписываются ссылки страницы НСПК и QR в режиме «Камерой телефона». Без него адрес берётся из `Host` и `X-Forwarded-Proto`. Заголовки `X-Forwarded-*` клиента в НСПК не уходят.

## Проверки

```bash
docker compose exec mirror php /var/www/tests/unit_test.php
```

Маршрутизация, переписывание адресов, разбор списков банков, отсев опасных ссылок, сборка диплинков, рендер страницы и ресайз логотипа.

`tests/e2e.cjs` прогоняет страницу в headless Chromium как iPhone, Android и десктоп. Он показывает текст, ответы payment-link, запросы в обход зеркала, ошибки, диплинки и данные QR. Нужен пакет `playwright-core` с его Chromium:

```bash
npm i --no-save playwright-core && npx playwright-core install chromium
```

```bash
node tests/e2e.cjs https://127.0.0.1:8443/<QRC_ID> https://127.0.0.1:8443/nspk/<QRC_ID>
```

`E2E_PROFILES=iphone,desktop` гоняет только часть профилей, `E2E_SHOTS=<каталог>` сохраняет скриншоты. Динамический QR живёт ограниченное время, протухший даёт `400 RQ05014 «Значение uniQrId не найдено»`, и на `/nspk/` это видно как «QR‑код недействителен».

## Как устроена страница НСПК

Пригодится, когда НСПК что-то поменяет.

- Статика (`js/index.js`, `proxyapp/*.json`, шрифты) грузится с базы `"https://qr.nspk.ru/"` (со слэшем), её зеркало переписывает на себя.
- Хост диплинка берётся из литерала `px="https://qr.nspk.ru"` (без слэша) через `El(document.URL, px)`. Его переписывать нельзя, поэтому `https://qr.nspk.ru` без слэша остаётся как есть.
- Данные платежа: `GET upc.cbrpay.ru/v1/payment-link/<QRC_ID>` с proof-of-work в заголовках `X-Token-*`, их считает браузер. Без них ответ 403.
- Список банков: `widget.cbrpay.ru/v2/{sbp,dr}/members/qr` с `X-CLIENT-ID: 000000000000`, без него 400.
- `apiConfig.json` → `certBanner`: страница дёргает `crt.cbrpay.ru/check` и при ошибке просит ставить сертификат Минцифры. Через зеркало проверка проходит, баннера нет.
- На хостах с `localhost` в имени страница берёт статику с `/qr/`, зеркало понимает и этот префикс.
