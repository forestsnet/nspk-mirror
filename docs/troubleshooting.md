# Неисправности

Первым делом лог: `docker compose logs -f --tail=100 mirror nginx`.

| Симптом | Что смотреть |
|---|---|
| nginx в режиме HTTPS не стартует, в логе `cannot load certificate` | Нет сертификата в `LETSENCRYPT_DIR/live/<домен>/`. Выпустите его по шагам 2–3 из [HTTPS с Let's Encrypt](deployment.md#https-с-lets-encrypt) |
| 502 на странице или на `/nspk/` | `docker compose logs mirror`, строки `nspk-mirror: GET …`. Сервер не достучался до НСПК, проверьте `curl` из [требований](deployment.md#требования) |
| Своя рабочая ссылка показывает «Ссылка недействительна» | Мерчанта нет в `ALLOWED_MERCHANTS`. Строка `blocked` в `docker compose logs mirror` и `bin/link.php` показывают его ID |
| В шапке нет суммы и получателя | `docker compose logs mirror \| grep payment-link`. HTTP 403 — НСПК не приняла PoW: поменялись параметры или алгоритм в `apiConfig.json` и `js/index.js` либо врут часы сервера |
| На плитке буква вместо логотипа | Логотипа нет у самой НСПК или он не скачался. Заголовок `X-Mirror-Cache` у `/logo/40/<файл>` показывает, откуда ответ |
| Банк пишет «QR-код недействителен» | Динамический QR живёт ограниченное время, нужен новый платёж. На `/nspk/` это видно как `RQ05014 «Значение uniQrId не найдено»` |
| Покупатели получают 429 | Зеркало за прокси, и лимит считается по его адресам. Настройте `real_ip`, см. [Только HTTP](deployment.md#только-http) |
| Сломалась страница `/nspk/` | НСПК обновила свою страницу. Прогоните e2e на `https://qr.nspk.ru/<QRC_ID>` и на зеркало и сравните, ориентиры в [устройстве страницы НСПК](nspk-page.md) |
